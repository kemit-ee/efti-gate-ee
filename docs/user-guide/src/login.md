# Sisselogimine ja navigeerimine

## Sisselogimine

1. Ava eFTI värava haldusliides.
2. Rakendus suunab sind TARA autentimisteenusesse.
3. Vali sobiv autentimisviis ja lõpeta autentimine.
4. Eduka autentimise järel avaneb vaade **Väravad**.

Ligipääs õnnestub ainult siis, kui administraator on sinu isikukoodi eelnevalt vaates **Kasutajad** registreerinud. Kui autentimine õnnestub, kuid kasutajat eFTI väravas ei ole, juurdepääsu ei anta.

Kohalikus arenduskeskkonnas kasutatakse TARA testteenust ja testidentiteete. Tootmiskeskkonnas kasutatakse päris TARA teenust.

## Menüü kasutamine

![Haldusliidese ülamenüü](images/02-navigation.png)

- Aktiivne jaotis on tumedama taustaga.
- Keelevalik **ET/EN** muudab kasutajaliidese keelt.
- Kasutaja nime alt avaneb käsk **Logi välja**.
- Kitsal ekraanil avab navigatsiooni nupp **Menüü**.

## Väljalogimine

1. Ava paremas ülanurgas oma nimega menüü.
2. Vajuta **Logi välja**.

Väljalogimine tühistab aktiivse seansi. Jagatud arvutis sulge pärast väljalogimist ka brauseriaken.
